# Build the Extension

This skill describes how to build, install locally, and generate the package for the **DayNight Theme Sync** GNOME extension.

## Local Installation & Build

To install the extension locally for testing and to simultaneously generate the `.zip` package for the GNOME Extensions store, use the provided script at the root of the project:

```bash
./install.sh
```

### What this script does:
1. **Cleans** previous build artifacts from `./out/`.
2. **Compiles** GSettings schemas (`glib-compile-schemas`).
3. **Builds** the extension structure in the `./out/daynight-theme-sync@phenrique-coder.github.com` directory.
4. **Installs** the extension directly into your local GNOME Shell extensions folder (`~/.local/share/gnome-shell/extensions/`).
5. **Generates** the ZIP package (`daynight-theme-sync@phenrique-coder.github.com.zip`) in the project root.

## Uploading to GNOME Extensions Store

The `.zip` file generated by running `./install.sh` is fully ready for upload. 
Simply access the [GNOME Extensions website](https://extensions.gnome.org/upload/) and upload the `daynight-theme-sync@phenrique-coder.github.com.zip` file.

> [!NOTE]
> After running the script locally, remember that you need to restart GNOME Shell (logout/login on Wayland, or Alt+F2 -> `r` -> Enter on X11) to apply changes.
